# tesseract-harness

My own harness for building and testing. Prioritizes open-weight models, is built for privacy, and acts as a merger between existing harnesses.

This repository began from the open-source framework at [omnigent-ai/omnigent](https://github.com/omnigent-ai/omnigent). The maintained tesseract documentation lives in [README.md](README.md).
