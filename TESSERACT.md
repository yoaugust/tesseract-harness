# tesseract-harness

My own harness for building and testing. Prioritizes open-weight models, is built for privacy, and acts as a merger between existing harnesses (inspired by [Omnigent](https://omnigent.ai/)).

## Base project

This repository is based on [Omnigent](https://github.com/omnigent-ai/omnigent), an open-source AI agent framework and meta-harness. Its original project documentation remains in [README.md](README.md).
